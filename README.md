# Мини-магазин

Учебный проект: веб-приложение для продажи товаров.

## Цель
Отработать полный цикл разработки: планирование API, каталог, корзина, оформление заказа.

## Стек
- Frontend: HTML / CSS / JavaScript
- Backend: Node.js (план)
- Хранение: мок-данные на старте
