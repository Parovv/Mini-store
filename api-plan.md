# API Plan

## Товары
| Метод | Путь            | Описание              |
|-------|-----------------|-----------------------|
| GET   | /products       | список товаров        |
| GET   | /products/:id   | карточка товара       |

## Корзина
| Метод | Путь            | Описание              |
|-------|-----------------|-----------------------|
| GET   | /cart           | содержимое корзины    |
| POST  | /cart           | добавить товар        |
| PATCH | /cart/:id       | изменить количество   |
| DELETE| /cart/:id       | удалить товар         |

## Заказы
| Метод | Путь            | Описание              |
|-------|-----------------|-----------------------|
| POST  | /orders         | оформить заказ        |
| GET   | /orders/:id     | статус заказа         |

## Формат ответа
JSON. Ошибки: { "error": "message" }
